# docs

Docusaurus site for Gaia. The site root is the documentation. Schemas and
examples are read from `packages/spec` when the site builds.

## Sidebars and navbar

The top navbar has one item per section (**Docs**, **Guides**, **Specs**,
**Client SDK**, **Server SDK**). Each item uses `type: docSidebar` and shows
only that section’s sidebar
([multiple sidebars](https://docusaurus.io/docs/sidebar/multiple-sidebars)).

| Navbar label | Sidebar id  | Content folder     |
| ------------ | ----------- | ------------------ |
| Docs         | `docs`      | `docs/overview/`   |
| Guides       | `guides`    | `docs/guides/`     |
| Specs        | `spec`      | `docs/spec/`       |
| Client SDK   | `clientSdk` | `docs/client-sdk/` |
| Server SDK   | `serverSdk` | `docs/server-sdk/` |

Within each folder, use
[autogenerated](https://docusaurus.io/docs/sidebar/autogenerated) metadata:
`_category_.json` for subfolders and `sidebar_position` in front matter.

```bash
npm run start:dev -w docs
npm run build -w docs
```
